# ARCHIVE STUDIO — Clothing Design Portfolio

Static, public-ready portfolio website. No shopping or sales features are included.

## Included
- Premium black/white editorial visual direction
- Irregular curved line background elements
- T-Shirts and Pants categories
- Animated category switching and image reveal
- Click-to-expand artwork lightbox
- Direct Email contact via Gmail/mail client
- Direct Instagram profile link
- Responsive desktop/mobile layout
- Optimized local artwork assets

## Publish
Upload the entire contents of this folder to GitHub Pages, Netlify, Vercel, or any static hosting provider.

For GitHub Pages:
1. Create a public repository.
2. Upload all files/folders from this directory.
3. In GitHub: Settings → Pages → Deploy from branch.
4. Select the main branch and root folder.
5. GitHub will publish the site automatically.

No code changes are required for the included portfolio content and contact links.
